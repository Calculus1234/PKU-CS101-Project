## 工作约定（重要）

- 临时命令文件放 `Workspace\tmp\`，截图存 `Workspace\shots\`；不往工程根目录乱扔文件。
- **改 C# 后必须强制重编译再验证**（历轮教训：自动刷新有时不触发）。
- **重建场景后必须重跑"生成寻路网格"**（重建会清空烘焙数据，NPC 会退回直线兜底）。
- 机制优先：任何功能改动先对照《机制说明书》，冲突时以说明书为准。
- 安全红线：删除文件 / 目录须先经用户确认且走**回收站**；禁止 kill / taskkill 受保护进程（tac-server、tac-cli、qodercli、node、XLSmartTray、XLSmartUI、XLSmartService、天禧相关进程）。
- 每轮结束把手动做的改动写回 `Docs\交付说明.md`（追加轮次章节，格式参考往期）。
- 用 MCP 做 Play 自动化验证时，可在会话内临时 `Application.runInBackground = true`（编辑器失焦仍 Tick）；**不要改 ProjectSettings**，项目要求落盘 `runInBackground: 0`。
