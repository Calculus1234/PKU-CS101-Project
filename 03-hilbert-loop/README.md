# 《大限将至》（Hilbert Loop）

> **第一人称心理恐怖游戏**：在一座无限循环的密闭旅馆里，与八个戴面具的人一起，
> 搜证、监视走廊、参加圆桌辩论，在被投票淘汰之前找到真相。
> **已上架 itch.io：https://linzhongxike.itch.io/hilbert-loop**

## 一句话概括

玩家扮演 8 号，在一层 ∞ 形走廊的 9 个房间里搜证、私聊、开会、投票。
NPC 有**行为树 + 状态机**驱动的日程与反应，关键对话由 **LLM** 实时生成。

**核心玩法**（来自 itch.io 页面）：
- **监视恐怖**：盯着循环走廊——谁在游荡？谁在违规？
- **烧脑辩论**：收集物证、揭露矛盾，但每个人都在隐瞒
- **AI 驱动的 NPC**：本地 LLM（默认 1.5B）驱动记忆与求生本能，可以用**自由文本**审讯、欺骗或威胁
- **时间循环**：你死了，循环继续；在被时间齿轮碾碎前找出真相
- **多结局**：每揭开一个秘密，都会改变这一轮的命运

**硬件说明**：离线 AI 模型需要至少 8 GB 内存；没有独立显卡的话，
**在游戏里按 F9 切换到云端 API 模式**（支持 GLM / 任意 OpenAI 兼容接口），响应更快。

**语言**：英文 / 简体中文（设置里切换）。

## 故事内核

9 个人其实是同一个人的不同时间复制体。每轮结束所有人昏迷、记忆被删除，
并被注入「你是唯一杀手」的虚假认知。号码顺移，新复制体补位。

第一周目开局：1 号已经杀掉 9 号，玩家扮演 8 号，在自己房间醒来，
手里有一张写着「活过这一轮圆桌会议，不被投出，则你可以逃出生天」的纸条。

**完整机制见 [机制说明书](docs/机制说明书.md)。**

## 技术实现

### 1. NPC 行为树 + 状态机

NPC 不是简单的脚本触发器，而是有日程与动机的状态机：

| 模块 | 代码目录 | 作用 |
| :--- | :--- | :--- |
| 日程与状态 | `src/Scripts/NPC/`（57 个文件） | 起床、搜证、开会、私聊、投票的状态流转 |
| **寻路（A\*）** | `src/Scripts/NPC/NPCNavigator.cs`、`Bridges/AStarBridge.cs` | 详见 [寻路算法说明](docs/寻路算法说明.md)：f=g+h、Octile 启发式、两级降级、自动开门、卡死保护 |
| 行为树 | `src/Scripts/Core/` | 条件节点 + 动作节点的组合决策 |
| 证据系统 | `src/Scripts/Evidence/` | 线索的获取、持有、展示与推理链 |
| 会议与投票 | `src/Scripts/Meeting/`、`Voting/` | 圆桌会议的发言顺序与投票计票 |
| 交互 | `src/Scripts/Interaction/` | 玩家与 NPC、道具、场景的交互 |

### 2. LLM 对话

`src/Scripts/LLM/`（11 个文件）负责：

- 给 NPC 组装**人设 + 当前记忆 + 已知证据**的提示词；
- 对话结果结构化，回写到 NPC 的记忆与关系网络；
- 失败降级：LLM 不可用时退回模板对话，保证游戏可玩。

**两种推理模式，可切换：**

| 模式 | 实现 | 适用 |
| :--- | :--- | :--- |
| **本地 GGUF** | `LLMUnityBuild/` 本地运行时 | 离线、无 API 成本 |
| **线上 API** | `CloudLlmClient.cs`（OpenAI 兼容 + SSE 流式） | 效果更好、无需本地算力 |

- 线上支持任意 OpenAI 兼容服务：**智谱 GLM-4-Flash、DeepSeek、通义**等都能填
- `LlmSettings` 里 `llm.mode`：`0` = 本地，`1` = 云端
- **云端优先**：配置完整时先走 API，失败自动回退本地模型

### 3. 搜证与多结局

- 破局判定：玩家收集的证据链是否足以指认真凶；
- 多结局 A/B/C/D：由投票结果与搜证完成度组合决定。

## 如何运行

### 环境

- Unity 2022.3.62f3c1
- 场景：`Assets/Scenes/MainScene.unity`
- LLM 本地推理需要 `LLMUnityBuild/` 下的运行时（不包含在本仓库）

### 说明

**本仓库只包含自写源码**（`src/Scripts/`）。完整可运行版本需要：

- 场景与预制体（`Assets/Scenes`、`Prefabs`）
- 美术资源（`Assets/Art`）
- 第三方包：A* Pathfinding Project、LLMUnity
- 本地 LLM 模型文件

**推荐体验方式**：从 itch.io 下载已发布的完整版本。

## 局限

1. **LLM 对话的质量依赖模型**：本地小模型容易答非所问，需要提示词与后处理兜底。
2. **NPC 推理深度有限**：行为树是手工设计的，无法泛化到未预设的局面。
3. **搜证自由度高但引导弱**：玩家可能卡在不知道下一步该查什么。
