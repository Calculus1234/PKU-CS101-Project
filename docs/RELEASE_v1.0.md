### ③ PetFramework 桌宠框架（Release 版本：Furina）

**这一项交的是框架，不是单个桌宠。** 同一份代码驱动了**四个角色**
（白虎「小白」、青龙、猫、芙宁娜），内置**毛发 / 鳞片 / 金属**三种渲染接口——
换角色只需换模型 + 动画控制器 + 材质配置，框架代码零改动。

| 平台 | 文件 | 说明 |
| :--- | :--- | :--- |
| Windows | `Furina.zip` | 解压双击 `Furina.exe`（框架 + 芙宁娜角色） |

**注意：AI 对话需要自备 API Key。**

1. 解压后进入 `Build/`，把 `config.template.json` 复制成 `config.json`
2. 填入你的 Key（模板默认指向硅基流动 `https://api.siliconflow.cn/v1`）
3. **不填 Key 也能运行**——宠物动作、拖拽、托盘都正常，只是不能聊天

### ④ 第一人称心理恐怖游戏《大限将至》（Hilbert Loop）

**本游戏有完整的 Windows 构建，但不在本 Release 中——已发布在 itch.io：**

> 🔗 **itch.io 页面：** https://linzhongxike.itch.io/hilbert-loop

**为什么用 itch.io 而不是 Release 附件**：
- 完整构建 `Hilbert-Loop.zip` 为 **3.87 GB**，超过 GitHub Release 单文件 2 GB 上限
- itch.io 是独立游戏的正式分发渠道，也是本项目的对外展示页

**游戏简介**（第一人称心理恐怖）：在无限循环的密闭旅馆里与八个戴面具的人共存，
搜证、监视、参加圆桌辩论；NPC 由 LLM 驱动，支持**自由文本**审讯。

**硬件说明**：本地 AI 模型（默认 1.5B）需要 8 GB 内存；
无独立显卡时**在游戏里按 F9 切换到云端 API**（支持 GLM / OpenAI 兼容接口）。

**技术要点**：NPC 行为树 + 状态机、A\* 寻路、LLM 双模式（本地/云端）、多结局系统。
算法细节见 [`03-hilbert-loop/docs/寻路算法说明.md`](https://github.com/Calculus1234/PKU-CS101-Project/blob/main/03-hilbert-loop/docs/%E5%AF%BB%E8%B7%AF%E7%AE%97%E6%B3%95%E8%AF%B4%E6%98%8E.md)。

## 已知限制

**解牌器**
- 只支持一对一明牌残局
- 极端零散局面可能超时（会明确提示「未完成」，**绝不返回错误结论**）
- 手机端大局面约 15~25 秒（PC 的 3~4 倍，受 CPU 与内存带宽限制）

**暗棋引擎**
- 对开发者本人胜率 < 30%（本人比 AI 强），对其他玩家全部获胜
- 内置拟人模型的胜率：Aggressive 98%，其余风格 72~90%（仍在优化）
- 搜索按实际耗时截断，机器负载会影响可达深度

**桌面宠物**
- 仅 Windows
- 聊天功能依赖外部 LLM 服务；不配置也能使用基础功能

**《大限将至》**
- 本地 LLM 推理需要 `LLMUnityBuild/` 运行时与模型文件（不在仓库中）
- 推荐直接玩 itch.io 版本

## 从源码验证

四个项目中，**解牌器的算法核心零 Unity 依赖**，可以完全脱离引擎验证：

```bash
# 需要 .NET 8 SDK
dotnet run --project 02-poker-solver/src/Cli -- --test
```

输出应为 8 个用例全部 PASS。这是「结果可复现」的直接证据。

**其他三个项目需要 Unity 2022.3 + 各自的第三方资源**，详见各子项目的 README。
