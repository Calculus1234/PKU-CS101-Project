## 已知限制

**解牌器**
- 只支持一对一明牌残局
- 极端零散局面可能超时（会明确提示「未完成」，**绝不返回错误结论**）
- 手机端大局面约 15~25 秒（PC 的 3~4 倍，受 CPU 与内存带宽限制）

**暗棋引擎**
- 对开发者本人胜率 < 30%（本人比 AI 强），对其他玩家全部获胜
- 内置拟人模型的胜率：Aggressive 98%，其余风格 72~90%（仍在优化）
- 搜索按实际耗时截断，机器负载会影响可达深度

**桌面宠物**
- 仅 Windows
- 聊天功能依赖外部 LLM 服务；不配置也能使用基础功能

**《大限将至》**
- 本地 LLM 推理需要 `LLMUnityBuild/` 运行时与模型文件（不在仓库中）
- 推荐直接玩 itch.io 版本

## 从源码验证

四个项目中，**解牌器的算法核心零 Unity 依赖**，可以完全脱离引擎验证：

```bash
# 需要 .NET 8 SDK
dotnet run --project 02-poker-solver/src/Cli -- --test
```

输出应为 8 个用例全部 PASS。这是「结果可复现」的直接证据。

**其他三个项目需要 Unity 2022.3 + 各自的第三方资源**，详见各子项目的 README。
