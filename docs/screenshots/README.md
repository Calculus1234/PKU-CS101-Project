## 拍摄建议

- **解牌器结果页**用 `4 5 6 7 8 J Q KK 小王 大王` vs `3333 44 55 6 77 9999 10 J QQ K A`（当前这副），结论是「无解 + 局面特征」，能体现「输也要说清楚为什么」。
- **模拟对抗页**要拍到红色的「对方制胜：3333」按钮和下面的「对方的制胜首手」文字——这是「必败也给解」的直接证据。
- **分页 UI 只在 Android 端有**（小屏放不下全部候选），PC 端不需要，截 PC 图时不要期待看到翻页按钮。
- 截图时关掉桌面上的其他窗口；桌宠会在顶层窗口上出现，不想让它入镜就先退出桌宠。
- 分辨率不用压，PNG 原样即可（主文档按 60% 宽排版）。
