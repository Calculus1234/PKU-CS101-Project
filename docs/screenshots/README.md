- **暗棋**：取自当前构建 `Chess-Windows64-v102` 实机画面，不是旧版 UI。
- **《大限将至》**：取自 `D:\MyGame\大限将至\ScreenShots\1.png / 5.png / 4.png`

- 所有图片统一缩放到宽 1600 px，PNG。
