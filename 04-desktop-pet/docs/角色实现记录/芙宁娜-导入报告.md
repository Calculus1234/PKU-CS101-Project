# Furina 导入报告（2026-10-20）

## 一、提取成功的动作文件清单

**官方动画：0 个。**

原因：GIAssetLib 需要 `studio/AssetStudio.CLI.exe` + `hk4eXX.index` + 数据块下载，
当前环境三样都不具备（详见 `Source/README_提取说明.md`），按委托要求记录后跳过。

替代方案：在 Unity 里程序化生成了 3 个 Humanoid 动作（muscle 曲线）：

| 文件 | 时长 | 内容 |
|---|---|---|
| `Assets/Animations/Furina_Idle.anim` | 2.0 s 循环 | 轻微呼吸（Spine/Chest 前后倾、头部微动） |
| `Assets/Animations/Furina_Walk.anim` | 1.0 s 循环 | 双腿前后交替 ±0.30、膝盖屈伸、手臂反向摆动 |
| `Assets/Animations/Furina_Run.anim` | 0.7 s 循环 | 同 Walk 放大到 ±0.60、躯干前倾 |

⚠️ 人形动画必须显式写 `RootT/RootQ` 曲线，否则 Hips 会被归零、整个人塌到脚下（已踩过并修复）。
⚠️ 肌肉曲线的属性名是 `HumanTrait.MuscleName`（带空格，如 `Left Upper Leg Front-Back`），
   写成 `LeftUpperLeg.z` 是**不生效**的（已实测）。
