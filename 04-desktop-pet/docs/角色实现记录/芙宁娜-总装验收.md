## 打包时踩到的坑（都写进代码了）

1. **`useFlipModelSwapchain` 必须关** —— 黑屏的真凶。
2. **URP 相机后处理必须关** —— 否则 alpha 被写成 1，整窗不透明。
3. **HoyoToon 材质必须 Lock** —— 否则 shader 被剔除，人物变品红。
4. 构建时会弹 `Shader Optimizer: Unlocked Shader`，点 OK 即可（材质已经锁好，产物不受影响）。
5. `TransparentWindow.useHitTestHook` 默认关 —— WM_NCHITTEST 原生回调里抛异常会直接带崩进程；真正起作用的是逐帧切 `WS_EX_TRANSPARENT`。
6. `CursorNearPet` 改成取**所有渲染器包围盒的并集**（原来只取第一个，正好是她脚下缩放为 0 的水球 → 命中区消失）。
7. `PetWindowManager`：面板关着时不再让 Tab 让位给输入框（否则 `IsTyping` 恒真，Tab 永远打不开面板）。

# 大小滑杆「看不见」的修复 + 两个工程重新打包 · 2026-10-23 22:45

## 为什么看不见

1. 设置页的滚动内容高度是**写死的**（芙宁娜 760 / 小白 820）。加了 TTS 四个输入框 + 滑杆之后总高超过它，
   后面的行被 ScrollRect 的遮罩裁掉 —— 滑杆正好在裁掉的区域里。
2. 就算高度够，滑杆也在页面最底部，要滚很久才能看到。

## 改法

- `content.sizeDelta = new Vector2(0, Mathf.Abs(y) + 60);` —— 按实际内容撑高，不再写死
- 把「桌宠大小（占屏幕高度 %）」**挪到设置页第一行**（在「接口配置」之前），进页面就能看见

实测（编辑器内）：滑杆行 `y=-54`、屏幕坐标 `(467, 306)`（视口高 443）→ **首屏可见**。
