### 4. 「两只胳膊不见了」的真相
- 不是蒙皮坏了：右臂顶点离臂骨平均 **0.038–0.062 m**，网格里手臂顶点齐全；
- 真正原因是 **场景文件里存着上一次 Play 的交叉手臂姿势**（双手在胸前/脸前 0.17–0.21 m），被大披风挡住，看起来像没胳膊；
- 处理：用 **bindpose 反向计算**把 469/431 根骨骼全部还原成 T-pose 并保存场景（现在打开场景就是标准 T-pose，手在 x=±0.41）；
- 另外把默认待机从「荧的抱手待机」换成 **IdleBlink1 等手臂自然下垂的待机**（手在 y≈0.83、x≈±0.24），大幅减少披风/手臂穿插；荧的待机保留为 `idle_gen`。

### 5. 穿模说明
- 动作来自别的体型（Miku/荧），芙宁娜的披风、大袖口在这些动作里会被手臂穿过；
- 已通过「换默认待机 + 手臂自然下垂的待机池」缓解；重击的交叉手姿势仍可能穿披风，属于跨模型动作的固有问题，彻底解决需要给披风加骨骼物理。


### 6. 裙摆/披风「内侧纹理消失」的真正原因（2026-10-20）
- HoyoToon 的片元里有一行：
  `float2 uv_a = (!vface && _UseBackFaceUV2) ? i.uv_a.zw : i.uv_a.xy;`
  即**背面默认改用第二套 UV 采样**；
- 这个 PMX 的 `addUV = 0`（没有第二套 UV），Blender 导出的 `uv2` 里 26242 个顶点只有 4531 个非零、其余全是 (0,1)
  ⇒ 所有内侧面都采到同一颗像素 ⇒ 看起来就是“素色、纹理没了”；
- 修复：把两具身体共 **63 个材质的 `_UseBackFaceUV2` 全部置 0**（直接改材质资产并保存）；
- 验证（同姿势 A/B 渲染）：下半身 **5.09% 像素变化**，局部细节量 **7.60 → 9.10**，内侧恢复纹理/阴影细节。

#### ⚠️ 「先掀后裙摆再坐下」做不了
- 这个 PMX 的 469 根骨骼里**没有任何裙摆/披风骨骼**（只有 `袖_1~4.L/R` 袖子骨）；
  裙摆和披风是直接蒙皮在 `下半身/腿` 上的，**没有可以独立掀起来的骨骼**；
- 因此**任何 VMD 都无法让它掀裙摆**——玩家在游戏里能用，是因为官方骨骼有裙子骨；
- 若一定要这个效果，只能给 PMX 手工加裙摆骨骼并重新蒙皮（大工程），或者坐姿时隐藏后摆。


### 8. 裙摆「两种贴图打架」的正解（2026-10-20）
- PMX 的裙摆有**共面的复制层**：`裙摆+ / 裙1+ / 裙2+`（面数与原层一一对应，是内衬，PMX 标记为单面）；
- Unity 里这些材质 `_Cull=0`（双面）+ 与原层几乎同一深度 ⇒ 两层贴图同时画在裙面上，看起来像“打架”；
- HoyoToon 这批材质上改 `_Cull` 实测对它们无效（渲染结果 0% 变化），改用最直接的办法：
  **把这 3 个内衬子网格的材质换成全透明 `M_Hidden`**（保留 `髮+` 头发层，别误伤）；
- 现在裙面只有一层贴图；内侧由外层的背面（`_UseBackFaceUV2=0` 后采样正常 UV）承担。
- 若之后觉得内衬颜色不对，可以再单独给这 3 个槽换一张纯色/衬里材质，而不是把整层打开。
