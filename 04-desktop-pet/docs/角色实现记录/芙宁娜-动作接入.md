## 二、为什么是这几个（而不是芙宁娜专属）

BowlRoll 全站检索 `フリーナ / 芙宁娜 / フリーナ モーション / フリーナ 待機`：

- `フリーナ` 只有 2 个结果，都不是动作（一个是相机、一个是宝石模型）；
- `芙宁娜` 只有 1 个结果「芙宁娜地才舞 配布」，**需要下载密钥 + 登录**，拿不到；
- 结论：**BowlRoll 上没有公开的芙宁娜待机/走路动作**。

于是在「官方原味」这一档里选了 **荧的官方待机描摹**（同为《原神》女性体型，风格最接近）；
走路 / 坐下用高质量通用 MMD 动作。同时把 **胡桃的官方待机**（#257704）也下下来了，
放在 `Source/VMD/unpack/257704_胡桃(原神)の待機モーション/`，想换随时可以换。

## 三、动作管线（可复现）

```
BowlRoll API 检索 → Playwright 下载 → 7z/zip 解包
    → Blender 5.1 (mmd_tools) import_model(PMX, scale=0.08)
    → import_vmd(VMD, scale=0.08)
    → （Walk 额外删掉「全ての親」位移曲线，去掉根位移）
    → export_scene.fbx(bake_anim=True, bake_anim_use_all_bones=True, step=1.0)
    → Unity ModelImporter 切三段 Sit 子 clip
```

脚本：`_tools/pmx_vmd_batch.py`（`blender -b -P _tools/pmx_vmd_batch.py -- normal|huang`）
日志：`_tools/batch_normal.log` / `_tools/batch_huang.log`

### 踩到的两个坑（都已解）

1. **走路 VMD 带根位移**：`全ての親` 每 40F 前进 15 MMD 单位（=1.2 m），到循环点跳回 0。
   直接用会在 Unity 里「走一步、闪回一次」。已在 Blender 里删掉该骨骼的 location 曲线
   （实测删了 3 条），变成**原地走**；位移交给 `FurinaDemoDriver`，速度按步幅定为 **0.9 m/s**。
   （作者 readme 原话：`400Fで１０ループの場合全親を「Z=-150」進める`，与实测一致。）
2. **两具身体的骨架根节点名字不同**（`【芙宁娜】_arm` / `【芙宁娜_荒】_arm`），
   Unity 的 Generic clip 是按 transform 路径绑定的 ⇒ **每个动作必须导出两份 FBX**。

| `Assets/Models/Furina_Huang_VMD.controller` | 同上 |

控制器参数（Trigger）：`doIdle`、`doWalk`、`doSit`、`doStand`

状态流：
```
Idle --doWalk--> Walk --doIdle--> Idle
Idle --doSit--> SitDown --(exit 1.0)--> SitLoop --doStand--> SitUp --(exit 1.0)--> Idle
```

### 脚本

- `Assets/Scripts/FurinaFormSwitcher.cs`（改）
  切换形态时不再写死 `"Dance"`，而是把**当前 state 的 shortNameHash + normalizedTime**
  搬到另一具身体的 Animator 上 ⇒ 走路中按 F 不会回到站立，动作无缝续播。
- `Assets/Scripts/FurinaDemoDriver.cs`（新）
  演示驱动：`WASD` 移动（0.9 m/s，与 VMD 步幅匹配，尽量不打滑），`C` 坐下/起身。
  只在**状态切换的那一帧**发 Trigger，并先 `ResetTrigger` 对手，避免残留 trigger 立刻弹回。

### 场景

`Assets/Scenes/SampleScene.unity`：`Furina_VMD` 上挂了 `FurinaFormSwitcher` + `FurinaDemoDriver`，
两个 Form 的 Animator 都指向新控制器，`applyRootMotion = false`，`PlayerSettings.runInBackground = true`。

## 六、已知限制 / 建议

1. **坐下是「椅子坐」**：原动作附带 `chair.x` 椅子模型。当前场景没有椅子，
   所以视觉上是「坐在空气上」（臀部高度约 0.42 m）。要更自然有两条路：
   - 在场景里摆一把椅子（把 `Source/VMD/unpack/267453_座る/座る/chair.x` 转成 FBX/或自建方块椅子）放在
     `(0, 0.44, -0.22)` 附近；
   - 或换成「体育座り / 地べた座り」的地面坐动作（BowlRoll 上多为 **pose（VPD）** 不是 motion，
     需要额外找）。
2. **Idle 是荧的官方待机描摹**，不是芙宁娜本人的；BowlRoll 无芙宁娜动作。
   想换更俏皮的风格，可改用 `Source/VMD/unpack/257704_胡桃(原神)の待機モーション/`（已下载）。
3. 走路是通用动作，步幅与芙宁娜的裙摆/高跟鞋不完全匹配；若要更贴，可在
   `Source/VMD/unpack/145537_mmd-motion-100walks-rev01/.../parts/` 里的 100 种步态中另选
   （`14_GoodPosture`、`19_Ballerina`、`24_Waiter` 这几个气质更接近），
   改 `pmx_vmd_batch.py` 的 `JOBS` 重跑即可。
4. **授权**：
   - 荧待机：`再配布禁止 / 改変自由`，出处注明 miHoYo；本地演示没问题，**别外传**。
   - 走路（SOLA）：无规约，改后再配布注明「改変 SOLA 的汎用歩き」即可。
   - 坐下（フユネコ＆朱雀）：自由使用，署名时写 `フユネコ＆朱雀`。
   - PMX 模型本身：原作者禁止二次配布，仅限个人使用。
